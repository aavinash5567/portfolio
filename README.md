## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create/open your portfolio repository (for example `aavinash1083.github.io`).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and `assets/` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for the published URL shown in the Pages section.

## Final checks before publishing
- Replace the LinkedIn placeholder and add a professional email.
- Verify that every project card links to its dedicated repository where available.
- Check project descriptions against the actual implementation.
- Add a resume PDF link if desired.
